# 📋 标书排版自检清单

> 打印出来贴在工位上，每次提交前逐项打勾。
> 
> 标记说明：🔴 必查（废标风险）| 🟡 重要（扣分风险）| 🟢 建议（加分项）

---

## 一、页面设置

- [ ] 🔴 页边距是否符合招标文件要求（常见：上下2.54cm，左右2.00cm）
- [ ] 🔴 纸张大小是否为A4（210mm × 297mm）
- [ ] 🟡 页眉页脚是否按要求设置
- [ ] 🟡 页码编号是否连续，目录页码与正文是否对得上

## 二、字体格式

- [ ] 🔴 正文字体是否符合招标文件要求（宋体/仿宋/黑体？）
- [ ] 🔴 正文字号是否正确（小四=12pt / 四号=14pt / 五号=10.5pt？）
- [ ] 🔴 一级标题字体字号是否正确
- [ ] 🟡 二级标题字体字号是否正确
- [ ] 🟡 三级标题字体字号是否正确
- [ ] 🟡 表格内字体字号是否正确（通常比正文小一号）

## 三、段落格式

- [ ] 🔴 首行缩进是否正确（通常2字符 = 0.74cm）
- [ ] 🔴 行距是否符合要求（1.5倍 / 固定28磅 / 单倍？）
- [ ] 🟡 段前段后间距是否统一
- [ ] 🟡 对齐方式是否正确（两端对齐 / 左对齐？）

## 四、标点符号（废标第一杀手）

- [ ] 🔴 中文正文里是否有英文逗号 `,`
- [ ] 🔴 中文正文里是否有英文句号 `.`
- [ ] 🔴 中文正文里是否有英文分号 `;`
- [ ] 🟡 中英文括号是否混用 `()` vs `（）`
- [ ] 🟡 是否有全角空格残留
- [ ] 🟡 数字与单位之间是否有空格（如"3 个月"应为"3个月"）

## 五、内容完整性

- [ ] 🔴 必须提交的章节是否齐全（对照招标文件文件清单）
- [ ] 🔴 占位符是否清零（搜"请填写""XXX""TODO""____"）
- [ ] 🔴 公司名称是否统一（全称/简称/投标人权用是否一致）
- [ ] 🟡 项目名称、编号是否与招标文件一致
- [ ] 🟡 投标截止时间是否正确
- [ ] 🟡 金额数字是否正确（大小写是否一致）

## 六、表格检查

- [ ] 🔴 表格是否有边框（招标文件通常要求"Table Grid"样式）
- [ ] 🟡 表格内文字是否居中对齐
- [ ] 🟡 表格跨页时是否有续表标题
- [ ] 🟡 报价表的算术是否正确（单价×数量=合价，逐行加总=总价）

## 七、图片检查

- [ ] 🟡 图片是否居中对齐
- [ ] 🟡 图片下方是否有图注（"图1 XXX"）
- [ ] 🟡 图片分辨率是否清晰（打印后能看清）
- [ ] 🟢 图片大小是否合适（不要撑满整页）

## 八、暗标专项（如适用）

- [ ] 🔴 全文是否有公司名称残留（搜公司全称/简称/缩写）
- [ ] 🔴 全文是否有公司地址残留
- [ ] 🔴 全文是否有公司Logo残留
- [ ] 🔴 全文是否有上一家客户名称残留
- [ ] 🟡 项目经理/技术负责人姓名是否已替换为"XXX"

## 九、最终检查

- [ ] 🔴 PDF预览一遍，看排版是否正常
- [ ] 🔴 打印一页样张，看实际效果
- [ ] 🟡 文件大小是否合理（太大可能图片太多，太小可能缺内容）
- [ ] 🟡 文件命名是否规范（项目名_投标文件_公司名_日期）

---

## 💡 使用建议

1. **打印这份清单**，贴在工位显眼位置
2. 每次提交前**逐项打勾**，一项都不能漏
3. 🔴 必查项漏了可能废标，**宁可多查一遍**
4. 跑脚本自动检查可以覆盖标点和格式项，**但内容项必须人眼看**
5. 建议两人交叉检查——你查我的，我查你的

---

## 🔧 自动检查命令

```bash
# 扫描全角半角问题
python scripts/md2docx.py 你的标书.md --scan

# 一键修复全角半角
python scripts/md2docx.py 你的标书.md --fix

# Markdown → Word（按config.yaml配置生成）
python scripts/bid_engine.py 你的标书.md -o 输出.docx

# 用指定模板生成
python scripts/bid_engine.py 你的标书.md --template government -o 输出.docx

# 生成后自动质检
python scripts/bid_engine.py 输出.docx --check
```
