# content.json 结构说明

`render_docx.py` 消费的输入文件。内容不写死编号，引擎自动渲染。

## 顶层结构

```json
{
  "meta": {
    "title": "项目名称",
    "bidder": "投标人名称",
    "date": "2026-08-10"
  },
  "body": [
    { "type": "h1", "text": "第一章 项目概述" },
    { "type": "p", "text": "段落文本..." }
  ]
}
```

## 块类型速查

| 类型 | 字段 | 说明 |
|------|------|------|
| `h1`~`h5` | `text` | 标题，自动编号 1 / 1.1 / 1.1.1 ... |
| `p` | `text` | 正文段落，首行缩进2字符 |
| `hnum` | `text`, `level` | 序号标题，level=0→（1），1→1），2→① |
| `list` | `items` | 列表，最多3级嵌套 |
| `table` | `title`, `header`, `rows` | 表格，分章自动编号 |
| `figure` | `title`, `img`, `width_cm` | 图片，分章自动编号 |

## 列表结构

```json
{
  "type": "list",
  "items": [
    "一级项",
    { "t": "一级项（有子项）", "children": ["二级项", "二级项"] },
    { "t": "一级项", "children": [{ "t": "二级项", "children": ["三级项"] }] }
  ]
}
```

## 表格结构

```json
{
  "type": "table",
  "title": "人员配置表",
  "header": ["序号", "岗位", "人数", "备注"],
  "rows": [
    ["1", "项目经理", "1", "持PMP证书"],
    ["2", "技术员", "3", "中级以上职称"]
  ]
}
```

## 图片结构

```json
{
  "type": "figure",
  "title": "项目组织架构图",
  "img": "images/org_chart.png",
  "width_cm": 14.0
}
```
`img` 路径相对于 content.json 所在目录。不传图片路径则生成占位文本框。

## 规则

1. 内容**不写死编号**（如"1.1"、"表1-1"、"（1）"），引擎自动生成
2. 标题只写文本（如"第一章 项目概述"），引擎自动编号并对齐
3. 表格和图片的分章编号基于当前 h1 计数
4. 一级标题默认另起一页（可通过配置关闭）
5. 正文段落不要手动加缩进，引擎统一处理
