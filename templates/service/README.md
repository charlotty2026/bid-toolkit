# 服务类投标文件大纲模板库

## 说明

本目录收录各类服务标的投标文件大纲模板。所有内容均来自公开招标文件范本、政府采购需求标准、行业规范和公开资讯，**不含任何企业特定信息**。

## 服务标通用骨架

从各类型服务标中提炼的通用章节结构，约80%的服务标适用此框架：

```
第一部分：商务标
├── 投标函（按招标文件给定格式）
├── 开标一览表
├── 报价明细表
├── 中小企业声明函
├── 法定代表人授权委托书
├── 营业执照及资质证书
├── 业绩证明材料
└── 其他商务文件

第二部分：技术标
├── 一、项目背景及需求分析
│   ├── 1.1 项目背景理解
│   ├── 1.2 服务需求分析
│   └── 1.3 重点难点及对策
├── 二、项目整体服务设想
│   ├── 2.1 服务总体思路
│   └── 2.2 服务目标及原则
├── 三、组织机构及人员配备
│   ├── 3.1 组织架构
│   ├── 3.2 人员配置方案
│   ├── 3.3 人员管理（招聘/培训/考核/替换）
│   └── 3.4 拟投入物资设备
├── 四、【核心服务方案】（按子类型替换）
├── 五、项目管理制度
├── 六、服务质量保障措施
│   ├── 6.1 质量标准
│   ├── 6.2 质量控制体系
│   └── 6.3 违约责任承诺 ★
├── 七、应急预案
├── 八、档案管理方案
├── 九、服务承诺及投诉处理
└── 十、同类项目业绩
```

⚠️ **违约责任承诺**：多数服务标评标细则要求必须包含违约责任承诺，遗漏直接0分。

## 子类型索引

| 子类型 | 文件 | 适用场景 |
|--------|------|----------|
| 咨询服务 | `consulting.md` | 土壤调查/环评/工程咨询/技术评估/专项规划 |
| 专职消防队 | `fire_fighting.md` | 企业/园区专职消防队外包、消防值守 |
| 档案管理 | `archive.md` | 档案数字化/档案整理/档案托管 |
| 人力外包 | `hr_outsource.md` | 劳务派遣/岗位外包/人力资源服务 |
| 物业管理 | `property.md` | 物业服务/后勤保障/保洁/保安/绿化 |
| 食堂餐饮 | *(可选)* | 食堂托管/团餐配送 |
| IT运维 | *(可选)* | 信息系统运维/技术支持 |
| 会务服务 | *(可选)* | 会议服务/接待服务 |

> **使用建议**：先根据招标文件评分项确定子类型，选取对应模板做骨架。若招标文件评分项与通用骨架差异大，按评分项重新组织章节顺序（评分项顺序 = 章节顺序）。
