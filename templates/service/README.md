# 服务类投标文件大纲模板库

## 说明

本目录收录各类服务标的投标文件大纲模板。所有内容均来自公开招标文件范本、政府采购需求标准、行业规范和公开资讯，**不含任何企业特定信息**。

## 服务标通用骨架

从各类型服务标中提炼的通用章节结构，约80%的服务标适用此框架：

```
第一部分：商务标
├── 投标函（按招标文件给定格式）
├── 开标一览表
├── 报价明细表
├── 中小企业声明函
├── 法定代表人授权委托书
├── 营业执照及资质证书
├── 业绩证明材料
└── 其他商务文件

第二部分：技术标
├── 一、项目背景及需求分析
│   ├── 1.1 项目背景理解
│   ├── 1.2 服务需求分析
│   └── 1.3 重点难点及对策
├── 二、项目整体服务设想
│   ├── 2.1 服务总体思路
│   └── 2.2 服务目标及原则
├── 三、组织机构及人员配备
│   ├── 3.1 组织架构
│   ├── 3.2 人员配置方案
│   ├── 3.3 人员管理（招聘/培训/考核/替换）
│   └── 3.4 拟投入物资设备
├── 四、【核心服务方案】（按子类型替换）
├── 五、项目管理制度
├── 六、服务质量保障措施
│   ├── 6.1 质量标准
│   ├── 6.2 质量控制体系
│   └── 6.3 违约责任承诺 ★
├── 七、应急预案
├── 八、档案管理方案
├── 九、服务承诺及投诉处理
└── 十、同类项目业绩
```

⚠️ **违约责任承诺**：多数服务标评标细则要求必须包含违约责任承诺，遗漏直接0分。

## 服务标推导法则（核心方法论）

服务标的子类型多到无法穷举（品牌宣传、活动策划、市场推广、展览展示、安保服务可单独可打包……），**不需要每个类型都建模板**。通用骨架 + 招标文件评分项反推即可：

```
第1步：读招标文件评分项，列出技术标所有评分维度
第2步：逐一匹配到通用骨架章节（背景→设想→组织→方案→制度→质保→应急→档案）
第3步：评分项中"服务方案/实施方案"部分 → 替换通用骨架第四章
第4步：评分项未覆盖的通用骨架章节 → 保底保留，简写即可
第5步：检查特有资质要求（从招标文件资格条件提取）
```

**示例**：品牌宣传服务标
- 通用骨架前三章不变（背景/设想/组织）
- 第四章替换为：品牌策略方案、媒介投放计划、创意内容生产、效果评估体系
- 特有资质：无特殊资质（除非涉及户外广告审批）

## 参考示例：常见服务类型速查

> 以下为已遇到过的服务类型示例，供参考。**本表不追求穷举**，遇到新类型直接用推导法则即可。

| 子类型 | 核心差异点（替换通用骨架第四章） | 特有资质/废标陷阱 |
|--------|--------------------------------------|------------------|
| 食堂餐饮/团餐配送 | 食品安全管理方案、菜谱设计、食材采购溯源、留样制度 | 食品经营许可证、健康证 |
| 会务服务/接待服务 | 会议服务流程、礼仪培训、会务物资管理、茶水服务标准 | 无特殊资质，人员仪容仪表要求严 |
| IT运维/技术支持 | 运维响应时效、巡检制度、故障分级处理流程、备件库 | ITSS/信息安全资质（视项目定） |
| 绿化养护 | 修剪/施肥/除虫计划、季节性养护、灌溉制度、补种方案 | 无特殊资质，农药使用许可证（如需） |
| 护工/护理服务 | 护理操作规范、老人/病人照护方案、医废处理 | 护理员证/护工证、健康证 |
| 救生员服务 | 泳池巡查方案、溺水急救流程、水质处理 | 救生员证、游泳教练证 |
| 医生/医务室服务 | 门诊流程、药品管理、医疗急救、传染病防控 | 医疗机构执业许可证、医师/护士执业证 |
| 城市管理信息采集 | 巡查路线规划、案件上报流程、专项普查方案 | 无特殊资质 |
| 供暖/供热运维 | 锅炉操作规程、供暖运行安排、水质化验方案 | 锅炉操作证、供热经营许可（如需） |
| 物流/配送服务 | 运输调度方案、仓储管理、GPS轨迹管理、安全管理 | 道路运输经营许可证 |
| 检测/检验服务 | 检测方法标准、仪器设备管理、QA/QC质控、报告编制 | CMA/CNAS资质 |
| 品牌宣传/推广 | 品牌策略、媒介投放、创意内容、效果评估 | 无特殊资质 |

> **使用建议**：
> 1. 有独立文件的5种类型 → 直接引用对应模板
> 2. 速查表中有 → 用通用骨架 + 替换第四章 + 注意特有资质
> 3. 速查表中无 → 用推导法则，从招标文件评分项反推
> 4. 遇到新类型有深度沉淀价值 → 加一行到速查表，够格再建独立文件
