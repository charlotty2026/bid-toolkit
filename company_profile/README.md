# 企业资料库 — 投标可行性分析用

本目录存储企业资质、业绩、团队等信息，供 `bid analyze --profile` 命令使用。

## 使用方法

```bash
# 分析招标文件，自动匹配企业资料
bid analyze 招标文件.md --profile company_profile/ -o 分析报告.md
```

## 文件说明

| 文件 | 用途 | 必填 |
|------|------|------|
| `team.md` | 核心团队配置（项目经理、技术负责人等） | ✅ |
| `qualifications.md` | 资质证书（ISO、许可证、荣誉等） | ✅ |
| `performance.md` | 同类项目业绩经验 | ✅ |
| `config.yaml` | 企业自定义配置 | 可选 |

## 注意事项

- 所有数据均为示例/脱敏数据，请替换为真实信息
- 敏感信息（真实合同号、金额等）自行决定是否填写
- 建议将此目录加入 `.gitignore` 避免误提交
