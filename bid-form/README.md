# 标书智能生成器

填HTML表单 → 生成标准版标书文件（.md / .docx）

## 两种模式

### 模式A：纯HTML版（离线可用）
- 文件：`bid-form.html`
- 用法：浏览器直接打开（双击或 `file://` 协议）
- 填表 → 点「生成标书」→ 下载 .md 文件
- 然后在服务器上跑：`bid engine 文件.md` 出Word
- **优点**：零依赖，任何电脑都能开
- **建议安装**：`pip install bid-toolkit`（否则只能生成 Markdown）

### 模式B：服务器版（一键Word）
- 文件：`bid_form_server.py`
- 依赖：`pip install bid-toolkit flask`
- 启动：`python bid_form_server.py`
- 打开 `http://localhost:8080`
- 填表 → 点「生成Word」→ 浏览器直接下载 .docx
- 自动调用 `bid_engine` 完成全套排版（字体/缩进/表格/全角半角修复）

## 项目类型模板

表单支持按项目类型切换模板章节标题：

| 项目类型 | 第四章标题 | 4.1 | 4.2 | 4.3 | 4.4 |
|----------|-----------|-----|-----|-----|-----|
| 人力外包/物业 | 项目理解与服务方案 | 项目理解 | 重难点分析 | 保障措施 | 人员配置 |
| 货物采购 | 项目理解与技术要求 | 技术要求响应 | 货物配置清单 | 质量保证措施 | 交货与验收 |
| IT服务 | 项目理解与技术方案 | 技术方案概述 | 系统架构设计 | 实施方案 | 运维保障 |

## 脱敏模式

勾选「🕶️ 脱敏导出」后，生成的标书中所有公司名、联系人、电话自动替换为 `______`，适合给外部客户看标书框架。

## 自动保存

表单数据每30秒自动存到浏览器本地，刷新或关闭页面后重新打开，数据恢复。

## 文件结构

```
bid-form/
├── bid-form.html         # 纯HTML版（离线可用）
├── bid_form_server.py    # 服务器版（一键Word）
└── README.md             # 本文件
```
